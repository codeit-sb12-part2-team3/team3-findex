# 📈 Findex

---

> **외부 Open API와 연동하여 금융 지수 데이터를 제공하는 대시보드 서비스**

지수별 성과 분석, 이동평균선 차트, 관심 지수 등록 기능을 통해 금융 지수의 흐름을 직관적으로 확인할 수 있습니다.  
Open API 자동 연동 업데이트 기능을 통해 최신 금융 데이터를 빠르게 반영하여 신뢰성 있는 금융 지수 정보를 제공합니다.

<br/>

**프로젝트 기간:** `2026.05.14 ~ 2026.05.26`

## 👥 팀원별 구현 기능 상세

| 이름 | 담당 영역 | 주요 구현 기능 |
|---|---|---|
| 박교현 | 프로젝트 총괄 / Index Info | 일정 관리, 주요 지수 기능, Index Info CRUD, H2 개발환경 구성 |
| 여운정 | Dashboard / Auto Sync | 지수 차트, 성과 랭킹, 관심 지수, 자동 연동 설정 및 스케줄러 |
| 이주혜 | Open API | Open API 호출, 데이터 변환 및 저장, 응답 DTO 파싱, 예외 처리 |
| 이태형 | Open API 연동 | 지수 정보·데이터 연동, 연동 작업 목록 조회 |
| 정우진 | Index Data / Global | Index Data CRUD, CSV Export, 전역 예외 처리 / API 응답 구조 통일 |
